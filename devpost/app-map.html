🌱 Tagly App Map

A quick reference guide to how Tagly works and where each piece lives.

App Overview

Tagly is a phone-friendly, client-side web application for organizing daily notes by custom tags with deadline tracking. It requires no backend server or database—everything runs directly in the browser and persists using localStorage.

  • index.html — Semantic single-page HTML structure with views for Home (forms) and Notes lists.
  • styles.css — Mobile-first CSS with soft mint and cream gradients, pill-shaped buttons, and rounded cards.
  • app.js — Clean vanilla JavaScript managing state, local storage, tag routing, deadline calculation, and DOM updates.
  • favicon.svg — Lightweight, self-contained SVG sprout icon for the browser tab.

Reference Code Route

Follow an action through three main locations in the code:

Stop 1: Note Entry Form — index.html > #note-composer-form & app.js > initApp()

Listens for form submission (or Ctrl+Enter keyboard shortcut), reads the chosen tag chip and optional date, and passes them to addNote().

Stop 2: State & Storage — app.js > addNote() & app.js > saveState()

Constructs the note object with a unique ID, formatted creation date, and exact ISO timestamp, prepends it to state.notes, and serializes it to localStorage.

Stop 3: Card Rendering & Deadline Calculation — app.js > renderNotes() & app.js > computeDeadlineStatus()

Filters notes according to the active bubble view (All, Tag, or Deadline), calculates days left without timezone shifts, and builds the rounded note card DOM with tap-to-reveal edit/delete actions.

To Change This, Start Here

  • Change the default starting screen: In app.js, change let currentFilter = "home"; to "all".
  • Add or adjust pastel tag colors: In styles.css, look for .tag-card.pastel-* and .note-tag-badge.
  • Change deadline countdown phrasing: In app.js > computeDeadlineStatus(), adjust the returned strings (e.g. "Last day today" or "Time's up").

A Practice to Reuse

Plan visible boundaries before writing code:

Specifying exact, observable behaviors ahead of time (such as treating calendar dates locally so zero days shows "Last day today" instead of negative numbers, and deciding that Home holds only forms while other bubbles display notes) gave us unambiguous verification checks. Every feature was tested and confirmed working immediately, avoiding architectural drift.

How to Run Tagly

Double-click index.html in your file manager, or run a local static server:

python3 -m http.server 8000

Then visit http://localhost:8000 in any web browser.
